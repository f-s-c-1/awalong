# 阿瓦隆 · 微信小程序

线上多人社交推理桌游《阿瓦隆》的微信小程序实现：房间制对局（5-10 人）、服务端权威的游戏状态机、实时语音讨论、沉浸式暗色 UI。

## 技术栈

- 客户端：微信小程序原生（TypeScript）
- 服务端：Node.js + NestJS + WebSocket
- 存储：Redis（房间/对局态）+ MySQL（用户/战绩）
- 语音：腾讯云 TRTC 小程序 SDK（企业主体资质就绪后接入）
