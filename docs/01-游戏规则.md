# 阿瓦隆游戏规则（线上版规则基准）

本规则以桌游《抵抗组织：阿瓦隆》(The Resistance: Avalon) 官方规则为准，并针对线上小程序做了适配标注。

## 1. 基本信息

- 人数：5~10 人
- 阵营：正义（亚瑟忠臣）vs 邪恶（莫德雷德爪牙）
- 胜负：共 5 轮任务，正义方先完成 3 轮任务成功即进入"刺杀阶段"；邪恶方 3 轮任务失败直接获胜

## 3. 角色说明

### 正义方
- **梅林 (Merlin)**：知道所有邪恶方成员（莫德雷德除外），但不能暴露自己，被刺杀则正义方失败
- **派西维尔 (Percival)**：能看到梅林与莫甘娜（但无法区分谁是谁）
- **忠臣 (Loyal Servant)**：无特殊信息

### 邪恶方
- **刺客 (Assassin)**：正义方完成 3 轮任务后，可指定刺杀一人，若刺中梅林则邪恶方反败为胜
- **莫甘娜 (Morgana)**：在派西维尔眼中与梅林无法区分
- **莫德雷德 (Mordred)**：梅林看不到他
- **奥伯伦 (Oberon)**：邪恶方互相不认识他，他也不认识队友
- **爪牙 (Minion)**：普通邪恶方成员

## 5. 游戏流程

### 5.1 夜晚阶段（发牌后自动执行，线上自动化）
1. 每人私密查看自己的角色牌
2. 系统私密展示信息：
   - 邪恶方（除奥伯伦）互见队友（莫德雷德对梅林隐身但对队友可见）
   - 梅林看到所有邪恶方（不含莫德雷德）
   - 派西维尔看到梅林+莫甘娜（不区分）
3. 全员确认完毕后进入白天

### 5.2 组队阶段
1. 队长（按座位顺时针轮转）选择本轮任务所需人数的队员
2. 全员对该队伍公开投票：同意/反对
3. 同意票 > 半数 → 队伍成立，进入任务阶段
4. 否决 → 队长顺移至下一位，投票轮计数 +1
5. **连续 5 次组队被否决 → 邪恶方直接获胜**

### 5.3 任务阶段
1. 被选中的队员各自秘密出票：成功 / 失败
2. 正义方只能出"成功"；邪恶方可出"成功"或"失败"（线上强制约束：正义方界面无"失败"按钮）
3. 系统洗乱后公布本轮成功/失败票数（不暴露谁出的）
4. 按失败票阈值判定本轮任务成败，更新任务进度

### 5.4 刺杀阶段
- 正义方达成 3 轮任务成功后，刺客有一次机会指定刺杀一名正义方玩家
- 邪恶方可（限时）讨论后由刺客确认
- 刺中梅林 → 邪恶方胜；否则正义方胜

### 5.5 结算
- 公布所有人身份、任务记录、投票记录
- 支持"再来一局"（同房间重开，队长起始位轮换）

## 6. 线上适配规则

- **断线处理**：断线玩家保留座位，120 秒内可重连；关键投票阶段断线超时按"弃权"处理（组队投票弃权=反对；任务出票正义方默认成功、邪恶方默认成功）
- **发言计时**：组队阶段队长限时 60s 选人（可配置），超时自动随机补齐并进入投票
- **投票限时**：30s，超时按默认值处理
- **旁观**：满员开局后，新进入者为旁观者，只见公开信息
