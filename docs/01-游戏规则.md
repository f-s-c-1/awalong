# 阿瓦隆游戏规则（线上版规则基准）

本规则以桌游《抵抗组织：阿瓦隆》(The Resistance: Avalon) 官方规则为准，并针对线上小程序做了适配标注。

## 1. 基本信息

- 人数：5~10 人
- 阵营：正义（亚瑟忠臣）vs 邪恶（莫德雷德爪牙）
- 胜负：共 5 轮任务，正义方先完成 3 轮任务成功即进入"刺杀阶段"；邪恶方 3 轮任务失败直接获胜

|---|---|---|

## 3. 角色说明

### 正义方
- **梅林 (Merlin)**：知道所有邪恶方成员（莫德雷德除外），但不能暴露自己，被刺杀则正义方失败
- **派西维尔 (Percival)**：能看到梅林与莫甘娜（但无法区分谁是谁）
- **忠臣 (Loyal Servant)**：无特殊信息

### 邪恶方
- **刺客 (Assassin)**：正义方完成 3 轮任务后，可指定刺杀一人，若刺中梅林则邪恶方反败为胜
- **莫甘娜 (Morgana)**：在派西维尔眼中与梅林无法区分
- **莫德雷德 (Mordred)**：梅林看不到他
- **奥伯伦 (Oberon)**：邪恶方互相不认识他，他也不认识队友
- **爪牙 (Minion)**：普通邪恶方成员

### 推荐板子（默认配置）
| 玩家数 | 推荐角色组合 |
|---|---|
| 5 | 梅林、派西维尔、忠臣×1 / 莫甘娜、刺客 |
| 6 | 梅林、派西维尔、忠臣×2 / 莫甘娜、刺客 |
| 7 | 梅林、派西维尔、忠臣×2 / 莫甘娜、刺客、奥伯伦 |
| 8 | 梅林、派西维尔、忠臣×3 / 莫甘娜、刺客、爪牙 |
| 9 | 梅林、派西维尔、忠臣×4 / 莫甘娜、刺客、莫德雷德 |
| 10 | 梅林、派西维尔、忠臣×4 / 莫甘娜、刺客、莫德雷德、奥伯伦 |

房主可在建房时自定义角色组合（校验：邪恶方人数必须符合上表；梅林/刺客为必选）。

## 5. 游戏流程

### 5.1 夜晚阶段（发牌后自动执行，线上自动化）
1. 每人私密查看自己的角色牌
2. 系统私密展示信息：
   - 邪恶方（除奥伯伦）互见队友（莫德雷德对梅林隐身但对队友可见）
   - 梅林看到所有邪恶方（不含莫德雷德）
   - 派西维尔看到梅林+莫甘娜（不区分）
3. 全员确认完毕后进入白天

### 5.2 组队阶段
1. 队长（按座位顺时针轮转）选择本轮任务所需人数的队员
2. 全员对该队伍公开投票：同意/反对
3. 同意票 > 半数 → 队伍成立，进入任务阶段
4. 否决 → 队长顺移至下一位，投票轮计数 +1
5. **连续 5 次组队被否决 → 邪恶方直接获胜**

### 5.3 任务阶段
1. 被选中的队员各自秘密出票：成功 / 失败
2. 正义方只能出"成功"；邪恶方可出"成功"或"失败"（线上强制约束：正义方界面无"失败"按钮）
3. 系统洗乱后公布本轮成功/失败票数（不暴露谁出的）
4. 按失败票阈值判定本轮任务成败，更新任务进度

### 5.4 刺杀阶段
- 正义方达成 3 轮任务成功后，刺客有一次机会指定刺杀一名正义方玩家
- 邪恶方可（限时）讨论后由刺客确认
- 刺中梅林 → 邪恶方胜；否则正义方胜

### 5.5 结算
- 公布所有人身份、任务记录、投票记录
- 支持"再来一局"（同房间重开，队长起始位轮换）

## 6. 线上适配规则

- **断线处理**：断线玩家保留座位，120 秒内可重连；关键投票阶段断线超时按"弃权"处理（组队投票弃权=反对；任务出票正义方默认成功、邪恶方默认成功）
- **发言计时**：组队阶段队长限时 60s 选人（可配置），超时自动随机补齐并进入投票
- **投票限时**：30s，超时按默认值处理
- **旁观**：满员开局后，新进入者为旁观者，只见公开信息

## 7. 线上补充规则

### 7.1 角色板子合法性校验（建房阶段即校验，不允许开局后报错）
- 梅林、刺客为必选
- 派西维尔必须与莫甘娜同时启用，否则派西维尔可直接锁定梅林
- 奥伯伦不出现在邪恶方夜晚互认名单中，自己也看不到同伴
- 莫德雷德对梅林隐身，但邪恶方同伴可见
- 邪恶方人数必须等于第 2 节人数配置表

### 7.2 夜晚视野文案（避免新手误读）
| 角色 | 提示语 |
|---|---|
| 梅林 | 以下玩家是邪恶方（莫德雷德除外） |
| 派西维尔 | 以下两人中，一位是梅林，另一位是莫甘娜 |
| 邪恶方 | 以下是你的同伴（奥伯伦不在名单中） |
| 奥伯伦 | 你是邪恶方，但你不认识同伴，同伴也不认识你 |
| 忠臣 | 你没有额外信息，凭表决记录与发言推理 |

### 7.3 记录与笔记
- **公开战局记录**：系统自动记录每次组队的队长、队员、全员表决与任务结果，全程可查，所有玩家与旁观者可见；任务出票只公布成功/失败张数，不记录个人票
- **私人标记**：玩家可对任一座位标记"疑好 / 疑坏 / 存疑"并附 20 字备注，仅本机可见、不上传；房主建房时可关闭（默认开启）

### 7.4 发言秩序（可选模式）
- 默认自由发言
- **轮流发言模式**：队长提名后按座位顺序每人 30 秒（可配），非发言者麦克风音量压低至 20%（不静音），超时自动轮转到下一位

### 7.5 湖中女神（扩展，状态机预留 `LADY` 阶段，M3 实现）
- 7 人以上可启用；第 2、3、4 轮任务结束后，令牌持有者查验一名玩家阵营（仅自己可见）
- 令牌转移给被查验者，且不能查验曾持有过令牌的人

### 7.6 中途退出
- 游戏中玩家主动退出：保座 3 分钟等待重连；超时后房主可选"作废本局"（不计战绩）或"继续"（该座位按超时代投规则自动操作）
- 在座人数低于 5 人时强制作废
