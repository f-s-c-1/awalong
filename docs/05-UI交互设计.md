# UI / 交互设计

## 1. 设计定位

- 产品类型：社交推理桌游（消费级、强沉浸、多人同屏）
- 核心任务：**让玩家在 5 秒内看懂"现在是什么阶段、该谁操作、我要做什么"**
- 视觉基调：中世纪奇幻 + 暗色沉浸。装饰服务于氛围，不侵占信息层级

## 2. 视觉规范

### 配色（暗色单主题）
| 用途 | 色值 | 说明 |
|---|---|---|
| 背景 Background | `#141019` | 深夜紫黑，营造圆桌夜谈氛围 |
| 表面 Surface | `#1F1A2B` | 卡片/面板 |
| 主色 Primary | `#C9A227` | 亚瑟金，仅用于当前可操作按钮与队长标识 |
| 正义方 | `#4C8DFF` | 蓝 |
| 邪恶方 | `#D64545` | 红 |
| 正文 Text | `#EDE8F2` | 对比度 ≥ 4.5:1 |
| 次要 Text | `#9B93AB` | |

规则：红/蓝只用于阵营语义（任务结果、身份、结算），不作装饰色；金色全局同屏最多出现一处（当前行动点），保证视线引导唯一。

### 字体与尺寸
- 正文 14-16px（28-32rpx），阶段标题 20px，倒计时数字 32px 等宽字体
- 图标用 SVG 单色描边（自绘中世纪风格：盾、剑、王冠、卷轴），16-24px
- 圆角：卡片 12px，按钮 8px；阴影 `0 2px 8px rgba(0,0,0,0.3)` 封顶
- 触控目标 ≥ 44×44px；动效 150-300ms，仅 opacity/颜色过渡，翻牌动画除外（3D flip 400ms）

## 3. 页面结构

```
pages/
├── index/        # 首页：创建房间 / 加入房间 / 我的战绩
├── room/         # 房间大厅（LOBBY）
├── game/         # 游戏主桌面（单页承载全部游戏阶段）
├── result/       # 结算复盘
└── rules/        # 规则说明（新手引导图文）
```

## 4. 关键页面设计

### 4.1 首页
- 竖版布局：Logo 区（剑与圆桌插画）→ 两个主按钮「创建房间」「加入房间」→ 底部次级入口（战绩 / 规则）
- 加入房间：弹出 6 位数字键盘输入房间码，支持粘贴识别
- 创建房间：底部抽屉选人数（5-10 分段控件）→ 展示该人数的默认角色板子 → 「高级配置」折叠区可勾选莫德雷德/奥伯伦等（实时校验合法性并提示）

### 4.2 房间大厅（LOBBY）
- 顶部：房间码大字号展示 + 「复制」「邀请好友」（微信分享）+ 小程序码入口
- 中部：环形座位图（与游戏桌面同构，降低认知切换成本），每个座位显示头像/昵称/准备状态勾标，空位显示「+」
- 底部：角色板子横向卡片列表（可点开看角色说明）；房主见「开始游戏」，玩家见「准备」
- 语音：右上角麦克风按钮（TRTC 接通后显示说话音浪指示）

### 4.3 游戏主桌面（核心页面）

单页状态机渲染，布局分四层，所有阶段共用骨架：

```
┌──────────────────────────────┐
│ ① 任务进度条：5个圆盾(蓝✓/红✗/灰) │
│    + 否决计数 5 个小圆点          │
├──────────────────────────────┤
│                              │
│ ② 环形圆桌座位区                │
│    头像 + 座位号 + 状态徽标      │
│    (👑队长 / 🗡被提名 / 说话音浪) │
│                              │
├──────────────────────────────┤
│ ③ 阶段信息条：                  │
│   "队长 3号 正在选择 2 名队员"    │
│    + 倒计时                    │
├──────────────────────────────┤
│ ④ 操作区(随阶段变化的按钮/卡牌)   │
└──────────────────────────────┘
```

各阶段操作区形态：

| 阶段 | 操作区内容 | 交互细节 |
|---|---|---|
| 夜晚看牌 | 居中角色卡（点击 3D 翻牌），下方私密视野名单 | 长按可复看；「我记住了」确认后卡牌收入右上角「查看身份」浮钮（防偷看：再次查看需长按 1s） |
| 组队(队长) | 点击座位头像选人，选中头像加金色描边+🗡；满员后「确认出征」亮起 | 非队长玩家此时看到队长头像呼吸金光 |
| 组队投票 | 两张大按钮牌「同意(蓝)」「反对(红)」 | 投出后牌面盖下显示"已投"，全员投完 → 所有票**同时翻开**在各自头像下方（保留桌游同步亮票仪式感） |
| 任务出票 | 队员见「成功」「失败」两张牌；**正义方只渲染成功牌**（另一张为不可点的灰牌并注明"忠臣只能成功"） | 非队员看到队员头像上的沙漏动画 |
| 任务揭晓 | 居中洗牌动画 → 逐张翻开成功/失败票（乱序） | 翻到失败票时红光震屏 100ms，强化戏剧张力 |
| 刺杀 | 刺客点击正义方头像 → 二次确认「刺出致命一击」 | 其他玩家看到"刺客正在寻找梅林…"的剑光扫描动画 |

### 4.4 结算页
- 第一屏：胜负大图（正义金光 / 邪恶红雾）+ 一句话胜因（"刺客刺中了梅林"）
- 第二屏：全员身份揭示（环形座位图上翻开所有角色牌）
- 第三屏：复盘时间线——每轮任务的队长、队伍、投票明细表（这是推理玩家最爱看的部分，做成可展开的轮次卡片）
- 底部：「再来一局」（全员回大厅，保留座位）/「退出房间」

## 5. 全局交互细节

- **阶段切换**：全屏 toast 式横幅（如"第 3 轮任务 · 投票阶段"）800ms 自动消失 + 轻震动 `wx.vibrateShort`
- **身份防泄露**：查看身份需长按；截屏监听 `wx.onUserCaptureScreen` 弹提示"截屏泄露身份将破坏游戏体验"
- **弱网提示**：WS 断开时顶部红条"重连中…"，页面操作禁用但不清空
- **倒计时**：最后 5 秒数字变红 + 每秒轻震动
- **快捷短语**（无 TRTC 时的主要沟通手段）：操作区上方横向滚动 chips——「我是好人」「上我」「反对这队」「1/2/…号可疑」，点击后以气泡形式出现在发送者头像旁 3s
- **新手引导**：首局强制 30 秒图文引导（阵营目标 → 看牌 → 组队投票 → 出任务），可跳过

## 6. 无障碍与适配

- 阵营色同时配形状语义（成功=盾✓、失败=裂盾✗），不单靠红蓝区分（色弱友好）
- 适配 iPhone SE(375px) 至 Pad；圆桌座位区用 rpx + 半径按屏宽自适应
- 尊重系统字体缩放，关键数字（房间码、倒计时）用固定布局防溢出
